# Images Directory

This directory contains image assets for the MadaApp.

## Recommended Images

- `logo.png` - Application logo (512x512 px, transparent background)
- `onboarding/*.png` - Onboarding screen illustrations
- `categories/*.png` - Category-specific illustrations
- `badges/*.png` - Achievement badges and rewards

## Image Guidelines

- Use PNG format with transparency when needed
- Optimize images for mobile (use appropriate compression)
- Provide 1x, 2x, and 3x variants for different screen densities
- Maximum recommended size: 2MB per image
