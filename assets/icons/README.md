# Icons Directory

This directory contains custom icon assets for the MadaApp.

## Recommended Icons

- Custom category icons (if not using Material Icons)
- Achievement/badge icons
- Navigation icons
- Custom UI elements

## Icon Guidelines

- Use SVG format for scalability (preferred)
- Or PNG with multiple sizes (24x24, 48x48, 96x96)
- Use consistent style across all icons
- Ensure icons work on both light and dark backgrounds
